    How it works

    From settings to timestamps

    1. Validate the inputs

      The shared planner checks the inclusive UTC date range, activity chance and daily count.

      src/planner-core.mjs

    2. Build the plan

      The seed makes the same settings yield the same daily counts and commit times.

      src/planner-core.mjs

    3. Write with Git

      The local app saves its preview and writes empty, dated commits in a new folder.

      src/repository.js

    What runs in your browser

    The hosted demo computes plans in this tab using Web Crypto. Your inputs stay in the tab. Repository creation uses Git on your computer and publishing is a separate terminal step.

    Run locally

    Create a real repository

    Install Node.js 22.12 or newer and a version of Git that supports git init -b.

    Read the setup guide
    1. Clone or download the GitHub repository.
    2. In the project folder, run npm ci, then npm start.
    3. Open http://127.0.0.1:3000, review a plan and choose Generate repository.
